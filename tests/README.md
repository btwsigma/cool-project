# Проверки

Статические проверки (без зависимостей):

```sh
node --check app.js
node --check oge-data.js
node --check oge.js
git diff --check
file assets/oge/*.pdf
pdfinfo assets/oge/oge-geography-demo-2027.pdf
```

Браузерный регрессионный тест использует Playwright как тестовую зависимость,
не подключаемую к сайту. Нужны Python 3 и Chromium-совместимый браузер.

```sh
npm install --prefix /tmp/oge-browser-tests --no-audit --no-fund playwright
NODE_PATH=/tmp/oge-browser-tests/node_modules node tests/oge-browser.cjs
```

По умолчанию запускается `/usr/bin/brave`; иной путь задаётся `BROWSER_PATH`.
Сервер запускается только на localhost:4178 и завершается после тестов.
Используется временный профиль браузера, реальные пользовательские данные не затрагиваются.
Внешние запросы блокируются: тест проверяет также работу без CDN комментариев.
Сетевые операции Supabase (публикация комментариев и оценок) не тестируются.

Покрытие: 30 упражнений ОГЭ и 29 уроков ЕГЭ, правильные/неправильные ответы,
показ и скрытие решений, чек-листы и перезагрузка, отдельный ключ localStorage,
повреждённое/недоступное хранилище, относительные PDF-ссылки и сигнатуры файлов,
внутренние ссылки, отсутствие горизонтального переполнения на ширинах
360/390/768 px и отсутствие необработанных ошибок JavaScript.
